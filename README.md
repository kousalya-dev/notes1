# Hanu S Kumar — Portfolio

Full-stack developer portfolio built with **React + Vite**: animated preloader, hologram-style portrait with parallax and orbiting tech chips, scroll-lit manifesto, animated impact stats and a stacked experience timeline.

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build → dist/
```

## Edit the content

Everything (bio, experience, skills, links) lives in [`src/data.js`](src/data.js).
Portrait: `public/hanu-cutout.png` (background removed). Résumé: `public/Hanu_S_Kumar_Resume.pdf`.

## Deploy to Vercel

Import this repo at vercel.com/new — Vercel auto-detects Vite (build `npm run build`, output `dist`).
